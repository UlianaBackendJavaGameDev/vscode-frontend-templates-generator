# ⚡ Modern Web Starter Pack Generator

Быстрый генератор готовой структуры веб-сайта для VS Code!

## 🚀 Что делает плагин?

Создает готовый шаблон адаптивного сайта в 1 клик с профессиональной файловой структурой:

- **`index.html`** — Семантическая разметка (Header, Hero, Form, Footer).
- **`css/reset.css`** — Полноценный обнуляющий сброс стилей.
- **`css/style.css`** — Тёмная тема, CSS-переменные, адаптивные блоки и стили.
- **`js/main.js`** — Базовый скрипт обработки интерактивных элементов.

## 💻 Как использовать:

1. Откройте пустую папку в VS Code.
2. Нажмите **`Ctrl + Shift + P`** (или `Cmd + Shift + P` на macOS).
3. Введите команду **`Generate Website Template`** и нажмите **Enter**.
